# 🎓 SIH Internal Participant Certificate Verification

> 🔐 A web-based certificate verification system developed for verifying Smart India Hackathon (SIH) Internal Participants.

---

## 📌 About the Project

This project is a **Certificate Verification Website** developed for the **SIH Internal Participant selection/verification process** at **St. Joseph's College of Engineering & Technology**.

The website allows users to verify participant certificate details using the available certificate information.

💡 The verification logic is implemented using **JavaScript**, with participant details maintained within the project files.

---

## ✨ Features

- 🔎 Certificate verification
- 🆔 Certificate ID based verification
- 👤 Participant details display
- ✅ Verification status
- 📱 Responsive user interface
- ⚡ Fast and lightweight
- 🎨 Clean and user-friendly design
- 🌐 Deployed as a live website
